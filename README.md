## 🇬🇧 English

An MG voiceover animation generator for product, interface, feature, launch and abstract-theme videos. Inputs can be product or packaging images, App and SaaS screenshots, voiceover scripts, audio, product documents, a real product, a fictional concept, or just a topic. It first judges the material type, whether the product is real or fictional, and what is missing, then uses an MG knowledge base to decide the main style, supporting visual modules and narrative structure — no default template and no mutually-exclusive style menu. It then writes a prompt document covering delivery specs, product setup, visual style, narrative structure, timed shots, on-screen text, voiceover, element motion, transition bridges, brand rules and audio design, and puts it on the canvas for review. Final animation generation starts only after explicit approval.

### ✨ What it does

- Script, audio, product image, App screenshot or bare topic → material type and gaps detected automatically
- Picks main style, supporting visual modules and narrative structure → never a default template
- Produces a prompt doc with delivery specs, timed shots, screen text, voiceover, motion, transitions and brand rules
- Prompt goes to the canvas for review first → final MG animation runs only after approval
- Distinguishes real products from fictional concepts → enforced by brand and product authenticity rules
- Covers style modules for product launches, UI demos and information visualization
